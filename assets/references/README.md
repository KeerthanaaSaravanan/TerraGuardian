# Reference UI Assets

## What

This directory is reserved for attributable visual references used when reviewing the Operations Centre and TerraGuardian Safe interfaces.

## Responsibility

Store approved screenshots or design exports here when they are added. Record source and date; do not treat an undocumented screenshot as a current behavior specification.

## Interfaces

The applications are implemented in `apps/operations-centre` and `apps/terra-guardian-safe`. Current components and design tokens are the implementation reference.

## Current implementation

No master UI screenshot or design export is currently stored in this directory.

## Verification and boundaries

There is no asset test or build step for this folder. A future screenshot reference will not prove that a UI flow or backend integration works.

## Local development

Add only reviewed, attributable visual references. No local command is required for this directory.
