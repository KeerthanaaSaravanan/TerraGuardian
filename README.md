# The Problem

Most hazard systems answer:

> **What may happen?**

Operational teams then have to answer:

> **What should happen next — and what can we legitimately conclude afterward?**

The difficult case is:

```text
             WARNING
                │
                ▼
          INTERVENTION
                │
                ▼
       NO OBSERVED EVENT
                │
       ┌────────┼────────┐
       ▼        ▼        ▼
    MODEL    ALTERED   EVIDENCE
     ERROR?  OUTCOME?    GAP?
